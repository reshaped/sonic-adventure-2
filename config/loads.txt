# The loads of make dc's GCC build that give a file of the disc a room of
# their own choosing, and the files each reads. The shipped loader reads
# these files unchecked. The GCC build's refuses one that doesn't fit its
# room, so a room smaller than a file of the disc loses the file.
# tools/dc_loads.py holds the table to the tree, and the disc's files to
# the table. Its docstring gives what a run checks.
#
# A row is FILES FORM BOUND HEADER ROOM SOURCE, then the file in words.
#
#   FILES   the files the load reads, as a pattern over the disc's paths in
#           config/jp-disc.sha256. * stands for any run of characters, ? for
#           any one, and [...] for one of those it lists
#   FORM    how the load reads a file:
#             file    loader_read_file_checked reads it into the room, in
#                     whole sectors
#             prs     loader_read_prs_checked reads it into WORK_AREA, in
#                     whole sectors, and decodes it into the room
#             buffer  loader_read_prs_buffer reads it into the room, in
#                     whole sectors, and decodes it there
#   BOUND   within, where the file may hold less than the room, or exactly,
#           where the load takes only a file that decodes to the room's bytes
#   HEADER  the header whose macros give the room
#   ROOM    the room, in bytes: a macro of HEADER, or the difference of two,
#           written NAME-NAME
#   SOURCE  the source whose load passes the room. It names each macro of
#           ROOM
#
# The table leaves out:
#
# - the programs, 1ST_READ.BIN and the 67 overlays, which the port builds.
#   tools/dc_memory.py holds each to the RAM its loader gives it;
# - a size the headers give no macro for, a struct's or an array's or a
#   count the game reads: the bytes an event's tracks must decode to,
#   e<event>_0.prs as a whole and each language's file, the bytes a stage's
#   lights must hold, the kindergarten's kbdtext_<language>.prs and the walk
#   game's image;
# - a load through WORK_AREA of a file the shipped loader reads through it
#   too, whose 2 MB both builds give: a texture archive, a set file, a sound
#   bank, a font or a table read by its name;
# - e0203.prs and e0210.prs, which no load reads: the event overlay reads
#   e0203.bin and e0210.bin for events 203 and 210;
# - what a load checks of a file's contents.
#
# files                                        form    bound    header                 room                                       source, then the file
