# Who reads the floats each source computes, its bin, which sets whether a
# build that isn't SHC's must keep the console's bits there. tools/parts.py
# reads the table, and tools/fmacs.py counts the fused products of each bin.
#
# A row is PATH BIN. PATH is a file, or a directory, which ends in /, and a
# file takes the row with the longest PATH that is the file or a directory
# above it. Each C source, header and .src file under src/, sdk/, modules/
# and engine/ takes a row, and some such file takes each row:
# tests/test_parts.py holds both.
#
# BIN is one of tools/parts.py's BINS:
#   play     a game step reads a float the source computes. A source whose
#            floats' reader isn't known is play, and so is a source that
#            computes play's floats beside the screen's
#   picture  only the screen takes the floats the source computes: what
#            lies below the draw calls, and the effects, the menus and the
#            screens no game step reads
#   none     neither a game step nor the screen takes them: the sound the
#            speakers play
#
# path                                    bin
