# The numbers for RAM that the port's sources, tables and generated data
# hold, and why each keeps its meaning where make dc's links lay out the
# images anew. tools/addresses.py checks the table, and its docstring names
# the numbers it reads.
#
# A row is FILE START [END] COUNT, then a disposition, then the reason. It
# explains the COUNT numbers FILE holds that are START, or that lie from
# START up to END. Each lies in START's view of RAM: 0x0c, 0x8c or 0xac.
# COUNT is a decimal number above 0, with no leading 0. The disposition is
# one of
#
#   anchor NAME  an area, a word or a bound of memory that no link places, so
#                that it keeps its address in the port. NAME is the macro or
#                symbol the sources name it by
#   placed NAME  a name a table gives, which the non-matching side takes as
#                NAME, a name the port's link places
#   data         no address, whatever its bits
#
# file                                           start       end         count  disposition, then the reason
# low memory, which the boot ROM and the system keep below 1ST_READ.BIN's
# image. The port links the resident at 0x8c010000 too
